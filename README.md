## Organización del Repositorio

- `src/`: Código fuente. Aquí viven las automatizaciones de los encargos.
- `docs/`: Documentación del proyecto y bitácoras.
- `equipo/`: Perfiles profesionales de cada integrante del equipo.
- `reporte-automatico/`: Proyecto de reporte automático de solicitudes (Opción A).
- `reporte-ventas/`: Automatización del reporte mensual de ventas de SNEAKER LAB.
- `CONTRIBUTING.md`: Reglas del equipo para ramas, commits y Pull Requests.
- `.gitignore`: Archivos y carpetas ignorados por Git (`.venv/`, `.env`, `__pycache__/`, etc.).

## Proyectos

### Reporte de Ventas — SNEAKER LAB

Automatización solicitada por Laura Restrepo, Gerente de Operaciones de
SNEAKER LAB. El proyecto parte de un archivo mensual de ventas con errores
intencionales y lo procesa para obtener el total vendido y los totales por
categoría.

Estado actual (issue #19): `reporte-ventas/generar_datos.py` genera
`reporte-ventas/datos/registros.csv` con 100 filas válidas y 6 filas dañadas
a propósito, usando únicamente la librería estándar de Python. Los detalles y
las instrucciones de ejecución están en
[`reporte-ventas/README.md`](reporte-ventas/README.md).
